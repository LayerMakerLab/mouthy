# Security policy

Mouthy listens to your microphone and types into other apps, so security problems matter. Thank you for reporting them responsibly.

## Reporting a vulnerability

Please report privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for security problems.

Include what you found, the platform and version, and steps to reproduce it. You will get a reply as soon as possible, and a fix will be released before details are made public.

## Scope

Examples of what counts:

- audio or text leaving the computer, or being saved when it should not be,
- typing into a password field or the wrong app,
- another user, web page or program using the agent server or `mouthy://` links,
- downloaded models or files being accepted without their checksum.

## Supported versions

Only the latest release receives security fixes.
